# hw1 - personal homepage

csc 4370 homework 1. it's my homepage for the class, one page that links to all my coursework (homework, cw, in-class stuff and projects).

- profile card with my name and an avatar
- about me, coursework hub, hobbies and contact sections
- nav at the top jumps to each section, and the section you jump to gets highlighted
- plain html + one external stylesheet (styles.css), no frameworks, no js
- works on phones, the profile card moves to the top under 900px

## how to run

just open `index.html` in a browser. or run `python3 -m http.server` in this folder and go to `localhost:8000`.

on codd it goes in `~/public_html/web/hw1/` so the url is https://codd.cs.gsu.edu/~rsharma30/web/hw1/index.html
