Who I am

I'm Rajan Sharma, a computer science student at Georgia State University graduating in December 2026.

Right now I'm taking CSC 4370 Web Programming, and this site is my Coursework 02 submission built with plain HTML5 and a basic stylesheet.

Outside of class I also build mobile and backend projects on my GitHub and practice deploying web pages to the GSU CODD server.

I got into computer science because I liked figuring out how apps and websites work under the hood and building things I can actually use. Outside of school I spend most of my free time at the gym weight training, watching movies, and working on side coding projects.

How I build a page

  1. Sketch out the basic sections of the page
  2. Write the HTML tags and structure first
  3. Fill in the text, images, tables, and links
  4. Add CSS rules and test mobile screen widths
  5. Check the page in the W3C validator
  6. Upload the files to CODD and test the live URL
