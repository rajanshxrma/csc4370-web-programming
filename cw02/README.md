# cw 02 - intro to html

csc 4370 coursework 02. a simple 3 page portfolio about me and the stuff i've built in the class so far.

- `index.html` home: intro, what's on the site, featured work, and an html5 overview video
- `about.html` about me: skills list, how i build a page, a projects table and a quote
- `projects.html` projects: cw01 git lab, my hw1 homepage draft and this site, plus a connect with me section
- images in `images/`, one small stylesheet in `css/`, `js/` is empty for now

## how to run

open `index.html` in a browser. the youtube video might not play from a file:// url, so run `python3 -m http.server` in this folder and go to `localhost:8000` if you want to see it work.

on codd it goes in `~/public_html/web/cw02/` so the url is https://codd.cs.gsu.edu/~rsharma30/web/cw02/
