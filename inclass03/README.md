# In-class 03: CSS Design

Rajan Sharma, CSC 4370 Web Programming.

Two small CSS challenges:

- `challenge1.html` animates the 3/4 answer with a `moveFraction` keyframe (yellow and off to the left at 0%, under the = sign at 50%, red next to the = sign at 100%), starting 1s after the page loads. Hovering the question highlights it.
- `challenge2.html` puts I heart NY on a plain white tee using relative positioning on the image, absolute positioning on the text and z-index to keep the text on top. The tee is `tshirt.svg`, which I drew myself instead of using a photo.

`index.html` links both and has my answers to the four critical thinking questions, plus screenshots I used to check the animation stages, the hover, and the shirt at desktop and phone widths.

To run it, open `index.html` in a browser. No build step and no JavaScript.
