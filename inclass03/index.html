critical thinking questions

1. positioning context

when an element uses position: absolute, its top and left numbers are measured from the closest parent element that has a position other than static. because the outer div has position: relative, the .first, .heart, and .last spans stay positioned inside that div.

if you delete position: relative from the div, there is no positioned parent anymore so the spans position themselves relative to the whole page window instead. then if the shirt moves down the page, the letters stay stuck up near the top corner instead of sitting on the shirt.

2. layering logic

z-index only works on elements that have a position like relative, absolute, or fixed. if an element is still position: static, the browser ignores z-index on it and just draws it in normal order.

in challenge 2 the shirt image has position: relative and z-index: 1, and the text spans have position: absolute and z-index: 2. if you change the spans to static or give the shirt a bigger z-index than the spans, the white shirt image covers up the letters so you cant see them.

3. animation performance

animating with transform: translate() is smoother than animating left and top because translate just moves the element visually without making the browser recalculate the page layout on every frame.

when you animate left and top, the browser has to redo layout calculations each frame. on one small word on a laptop it looks almost the same, but if you animate a bunch of items or run it on a slower phone, left and top can look choppy compared to transform.

4. design transfer

if i swapped the t-shirt for a hoodie picture, i would just need to change the top and left pixel numbers on .first, .heart, and .last because the chest area on a hoodie is lower down under the hood strings and the image size might be different.

the rest of the css setup stays the same though: a position: relative wrapper div, position: absolute on the text spans, and z-index so the text stays on top of the picture.
