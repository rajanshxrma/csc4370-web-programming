# cw05 - js form validation

rajan sharma, csc 4370 web programming, fall 2026.

javascript form validation lab checking id, first name, and last name fields with sequential error alerts, red inline messages above missing inputs, and dynamic result display below the form.

## files
- `index.html`: data entry form for id, firstname, and lastname with add button and output container
- `style.css`: form layout and red error message styling matching the lab specification
- `validation.js`: javascript validation logic using `innerHTML`, dom operations, sequential alert loop, field clearing, and last-entry display
