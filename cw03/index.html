critical thinking notes

1. specificity: when the same element matches a tag selector like p, a class selector like .verse, and an id selector like #chorus1, the id selector always wins even if it is written first in the css file because id is more specific than class and tag selectors.

2. 420px box without width 420px: if box-sizing is content-box, setting max-width: 380px and padding: 0 20px makes the total box width 420px in the devtools box model (380 + 20 + 20 = 420), or you can use flex-basis: 420px inside a flex container.

3. timetable mobile breakpoint: under 990px screen width, having white-space: nowrap on the table cells made the 5-day schedule wider than the screen. adding a media query at max-width: 989px with white-space: normal lets the text wrap inside the cells so it fits better.

4. color contrast: checked the timetable colors in chrome devtools color picker and used darker text colors on the light cell backgrounds so the schedule is easy to read.
