# HW2: My Movie Review

CSC 4370 homework 2. It's a Rancid Tomatoes style review page for TMNT (2007), rebuilt from the
reference screenshot with an external stylesheet. Grid handles the page regions, flexbox handles
the review columns and the critic lines, and it has breakpoints at 700px and 480px.

## Files

- `index.html` the page (XHTML syntax)
- `styles.css` all the styling
- `images/` the images from the assignment zip plus the two validator badges
- `evidence/` validator results, screenshots, measurements and my answers to the critical
  thinking questions (`evidence/answers.md`)

## Viewing it

Open `index.html` in a browser. Everything uses relative paths, so the folder works anywhere.
To check the breakpoints, open DevTools device mode and set the width to 700 and then 480.
